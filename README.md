# Supermart Grocery Sales - Retail Analytics Project

## Overview

This project analyzes and predicts sales for a supermarket using a real-world retail dataset. The workflow covers data cleaning, feature engineering, exploratory data analysis (EDA), and machine learning modeling to predict sales based on various features.

## Dataset

- Source: Supermart Grocery Sales Retail Analytics Dataset
- Columns: Order ID, Customer Name, Category, Sub Category, City, Order Date, Region, Sales, Discount, Profit, State

## Steps

1. Data Preprocessing Handle missing values, duplicates, and convert date columns.
2. Feature Engineering: Extract day, month, year from dates; encode categorical variables.
3. EDA: Visualize sales by category, trends over time, and feature correlations.
4. Modeling: Build and evaluate a linear regression model to predict sales.
5. Results: Visualize actual vs. predicted sales and interpret model performance.

## Requirements

- Python 3.x
- pandas, numpy, matplotlib, seaborn, scikit-learn

## How to Run

1. Place the dataset CSV in your working directory.
2. Open the Jupyter notebook and run all cells.
3. Review the visualizations and model results.
